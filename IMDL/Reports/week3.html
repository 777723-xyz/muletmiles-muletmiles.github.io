Weekly Report 2 due January 19, 2016

 

  This week I spent time getting familiar with my microcontroller board (the TI CC3200 launchpad) as well running a plethora of tests in the Unity3d engine to determine if my project was feasible. After about 5 iterations of coming up with an algorithm to follow a pink target ball, I was finally able to come up with OpenCV code that I was relatively happy with. I'm happy to report that, as of now anyway, I think that I'll be able to go through with my initial design. This week I plan to order the necessary motors/wheels in hopes that I can create a functioning robot by the end of next week.

       

        The algorithm that I ended up using involves keeping the target ball within the center of the camera screen. Because the tracking algorithm only provides an X and Y coordinate, I make additional decisions based on the calculated area of the target object (in this way, I very roughly approximate how close the ball is to the camera). Based on the tests in simulation, it appears that I'll need to run the code at at least 30 frames per second on the Jetson TK1; hopefully this won't be a problem given the speed of the development board.

        Of more concern is the motors; I need fairly responsive motors in order for the design to work; talking with family familiar with robotics filled me with optimism, but of course I will check with the TAs this week to ensure that the kind of responsiveness I need is possible from a DC motor. Worst comes to worse, the kind of responsiveness I need was demonstrated by a robot found here that uses modified servos:

  

 https://www.youtube.com/watch?v=t1GVBouubww#t=39

 

 While the speed of the above bot is not ideal towards my purpose, if I can get it to respond to directions with that speed, the design should function as intended. Also notable is that I've decided to use omni-directional wheels (as in the video) to move the robot; in this way, I can translate the robot without wasting any time to rotate in order to catch the ball. This aspect of the robots movement system has been identified as crucial, and should the omni-directional movement system fail, I'll have to resort to my back-up project.
